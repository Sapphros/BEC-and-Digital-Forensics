# Project Documentation Instructions

These instructions apply to this Sapphros portfolio repository.

- Every project README must contain sections titled exactly
  `Skills Demonstrated` and `What I Learned`.
- Put `Skills Demonstrated` near the top, after the project introduction.
- Keep actual results and investigation findings prominent.
- Write `What I Learned` using concrete observations from completed work.
- Ground skills, outcomes, and metrics in repository artifacts. Distinguish
  completed work from planned work, synthetic evidence from live telemetry,
  and automated checks from manual analysis.
- Preserve useful troubleshooting explanations and state material evidence gaps.
- Retain both required sections when creating, replacing, or restructuring
  a README. For a scaffold, label lessons as pending until work supports them;
  do not invent findings.
